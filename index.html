Tentang Saya

Antusias Belajar & Ngulik Kode

Kisah singkat di balik rasa penasaran saya terhadap dunia pemrograman dan teknologi.

"Dari penasaran cara kerja website, sampai ketagihan ngoding tiap malam."

Halo! Saya Arfyn Diazs, mahasiswa Teknik Informatika di Universitas Perjuangan (UNPER) Tasikmalaya. Bagi saya, pemrograman itu bukan sekadar mengetik baris kode, tapi wadah seru untuk memecahkan masalah logika dan mewujudkan ide menjadi aplikasi nyata yang interaktif.

Saat ini di bangku kuliah, saya aktif belajar algoritma dengan C++, menyusun struktur dan estetika lewat HTML & CSS, membuat interaksi dinamis dengan JavaScript, serta mengeksplorasi kemudahan Python dan sistem Database. Saya selalu bersemangat mempelajari hal-hal baru dan terbuka untuk diskusi santai seputar teknologi!
